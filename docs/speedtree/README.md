# SpeedTree in Dragon Age: Origins

Clean-room documentation of the SpeedTree 4 trees the game grows at load time.

- [format.md](format.md): where the files are, how levels place trees, the `.spt` file.
- [generation.md](generation.md): how a tree's geometry is computed from its file, in stages.

Rule for this work: the documentation is written by a session that has read SpeedTree
reference sources; the implementation is written by a different session that has not, from
these documents only. No code, type, function or file names from those sources appear here.
